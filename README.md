# CodeAlpha_Calculator
Modern calculator with keyboard support - CodeAlpha Frontend Internship Project


## 🎯 Project Overview

This calculator application provides a clean, intuitive interface for performing basic arithmetic operations with support for keyboard input and a responsive design.

## ✨ Features

- **All Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- **Keyboard Support**: Full keyboard functionality for faster calculations
- **Delete Function**: Remove last digit with DEL button or Backspace key
- **Clear Function**: Reset calculator with AC button or Escape key
- **Modern UI**: Gradient design with smooth animations
- **Responsive Design**: Works perfectly on all screen sizes
- **Error Handling**: Prevents division by zero
- **Real-time Display**: Shows previous and current operands

## 🛠️ Technologies Used

- HTML5
- CSS3 (with Gradients, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Google Fonts (Orbitron, Inter)

## 🎨 Design Features

- Modern gradient backgrounds
- Smooth button animations and hover effects
- Clean typography with custom fonts
- Professional color scheme
- Glassmorphism effect on display

## 🚀 How to Use

1. **Using Mouse**: Click on number and operator buttons
2. **Using Keyboard**: 
   - Numbers: 0-9
   - Operators: +, -, *, /
   - Calculate: Enter or =
   - Delete: Backspace
   - Clear: Escape

## 📱 Responsive Design

- Desktop: Full-sized layout with large buttons
- Tablet: Optimized medium-sized interface
- Mobile: Compact design for small screens
